# Travel Together — Static Travel Agency Website

A French-language travel agency website prototype built with plain HTML and CSS. It presents travel destinations, destination detail pages, an about page, and a contact page.

## Pages

- `p1.html` — home page and primary navigation
- `destinations.html` — destination listing
- `destination1.html`, `destination2.html`, `destination3.html` — Japan, Turkey, and South Africa destination pages
- `apropos.html` — about page
- `contact.html` — contact and reservation form mockups

## Run locally

No build step or package installation is required. From the repository root:

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000/p1.html> in a browser. The project does not have an `index.html`; `p1.html` is the home page.

## Scope and limitations

- The project is a static front-end prototype with local image assets and page stylesheets.
- Contact and reservation forms are UI-only; there is no backend, booking service, email delivery, or payment processing.
- The contact details in the page content appear to be sample values; confirm or replace them before presenting the site as a real business.
